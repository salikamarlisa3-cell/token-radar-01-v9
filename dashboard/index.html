Board Methodology

Every protocol on this board records no token in the competition snapshot — that is the snapshot's own wording for a protocol with no token record, and it is the only claim this page makes. Prices are model estimates built from the snapshot's own comparables, each with its fitted uncertainty interval; already-trading protocols are used only as comparables and are never ranked. One static snapshot, no live data, no network calls.
